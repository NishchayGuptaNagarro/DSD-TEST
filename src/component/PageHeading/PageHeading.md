## Overview
This component displays page heading, reason for creating this was same heading style is repeated throughout application.

### Inclusion

```
import PageHeading from '/component/PageHeading/PageHeading.tsx';
 
 <PageHeading heading={heading} subHeading={subHeading} />
```

### Use Case Description
1. Used for displaying page heading

### Component Designs

#### Input Props

1. heading:string -> Main page heading
2. subHeading:string -> Page sub heading (appears smaller)
